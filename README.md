# Todo App

A simple Kanban-style todo board that runs entirely in the browser.

## Built With

- 100% vanilla JavaScript, no frameworks or libraries for app logic
- HTML and CSS
- Font Awesome for icons (via CDN)

## Features

- Add new todos with title, description, and due date
- Edit existing todos, including moving between columns
- Delete todos
- Drag and drop cards across columns (Todo, In Progress, Completed)
- Per-column item counts
- Local storage persistence
- Basic form validation for required fields

## How To Run

1. Open index.html in a browser.
